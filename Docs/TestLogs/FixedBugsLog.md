# Fixed bugs log

Notable bugs found through testing, their root causes, and what changed. Newest first. Dates are the commit dates; every row links to the commit hash or issue that contains the change, so the timeline can be verified directly against the repository history. Day-to-day fixes live in commit history; this list keeps the ones that taught us something about the systems.
