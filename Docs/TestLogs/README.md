# Test Logs

Playtest and verification records for AlgoMon. One file per session, named
`YYYY-MM-DD_<topic>.md`.

## How to log a session

1. Copy `_template.md` to a new dated file.
2. Fill it in while playing, not afterwards.
3. Link every bug you fix to its commit or GitHub issue so the planning,
   testing, and fixing trail stays complete.
