# AI Use Declaration

AlgoMon was developed by **Jiachi Zhu** for the **Game Programming** module.
AI tools were used during development, disclosed below.

The game's **design — its ideas, mechanics, systems, and algorithms — was the
author's**. AI assistance was used mainly to help **implement parts of the script
code logic** and to **generate some of the image / animation art**. The author
directed the design, integrated, reviewed, tested, and validated the work, and is
responsible for the final submission.

## AI assistance with code

AI coding assistants — **Codex, Cursor, Claude (Claude Code), and ChatGPT** — were
used to help **implement, refactor, and debug** parts of the C# script code logic.
The author designed the architecture, gameplay, data structures and algorithms, then
reviewed, tested, and validated the generated code and all game logic.

## AI-generated and third-party assets

- **AI-generated art / animation:** AlgoMon sprites and animation frames (PixelLab);
  MainTerminal cover, typing loop, UI pieces, and the depth / switch / instruction
  icons (ChatGPT Image 2); element icons (Gemini 3.1 Pro / Nano Banana).
- **Third-party** packs, fonts, icons, music, and SFX are credited with their sources
  and licenses in `README.md` (🎨 Credits / 🎵 Music / 🔊 Sound Effects) and the master
  checklist `Docs/AssetAttribution.md`.

No third-party or AI-generated work is presented as the author's own hand-made content.

## Tools used

- **Image AI:** PixelLab, ChatGPT Image 2, Gemini 3.1 Pro / Nano Banana
